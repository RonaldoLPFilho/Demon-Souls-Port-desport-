# Memória dos agentes

Ponto de partida de todo subagente do desport. Leia nesta ordem, antes de qualquer tarefa:

1. `CLAUDE.md` (raiz): regras do projeto.
2. [rules.md](rules.md): o que um subagente pode e não pode fazer.
3. [knowledge.md](knowledge.md): base de conhecimento (engine, variáveis, descobertas, ferramentas).
4. `docs/STATUS.md` e `docs/ENGINE_BRANCHES.md`: estado atual e branches do engine.

Ao terminar, se você descobriu algo que o próximo agente precisa saber (um fato do engine, do jogo ou das
ferramentas que não está no código nem nestes arquivos), escreva no relatório final na seção
**"Para a memória"**. O coordenador decide o que entra aqui; não edite esta pasta por conta própria.

Mantida pelo coordenador (sessão principal). Atualizar sempre que uma tarefa mudar um fato registrado.
